# journeys (Phases P4–P5)

The journey state machine (ACTIVE → CHECKIN_DUE → FINAL_WARNING → ALERTED,
plus HELP_REQUESTED, SAFE, SAFE_LATE, CANCELLED, EXPIRED), deadline calculation,
check-ins (idempotent, including offline replays), extensions, cancellations,
help requests and contacts' informational responses.

Journey state is kept separate from notification delivery state.
